# Notebook · Anatomy

เว็บ 3D แบบ interactive ที่อธิบายโครงสร้างภายในของคอมพิวเตอร์โน้ตบุ๊ก — หมุนดูได้ทุกมุม
กดหยุดแล้วหมุนต่อได้ เลือกชิ้นส่วนขึ้นมาดูทีละชิ้นได้ และตัวเลขทุกตัวบนหน้าปัดมาจาก
แบบจำลองความร้อนชุดเดียวกับที่ทำให้พัดลมในภาพหมุน

สร้างด้วย skill `teardown` (three.js, หน้าเดียว ใช้งานออฟไลน์ได้ ~845 KB)

## วิธีใช้

เปิดไฟล์ `teardown-out/dist/notebook.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องมีเซิร์ฟเวอร์

| | |
|---|---|
| **ลากเมาส์** | หมุนรอบเครื่อง |
| **สกรอลล์** | ซูมเข้า-ออก |
| **SPACE / ปุ่ม PAUSE** | หยุดเครื่อง — กล้องยังหมุนได้อิสระ |
| **ปุ่ม SPIN** | หมุนรอบตัวเองอัตโนมัติ |
| **1–7** | กล้อง 7 มุม: HERO · TOP · FRONT · SIDE · UNDER · HINGE · MACRO |
| **คลิกชิ้นส่วน หรือคลิกชิปด้านล่าง** | เลือกชิ้นนั้นมาดูเดี่ยว ๆ พร้อมคำอธิบายภาษาไทย |
| **ESC** | ยกเลิกการเลือก |
| **E / X** | สลับโหมดแยกชิ้น / โหมดโปร่งแสง |
| **↑ ↓** | เพิ่ม-ลดภาระงาน CPU |
| **H** | ซ่อนหน้าปัดทั้งหมด |

ปล่อยทิ้งไว้เฉย ๆ หน้าเว็บจะเล่นทัวร์ของตัวเองพร้อมเคอร์เซอร์ให้ดู 80 วินาที
แตะตรงไหนก็ได้เพื่อเข้าควบคุมเอง เงียบไป 25 วินาทีมันจะกลับไปเล่นทัวร์ต่อ

### โหมด 5 แบบ

- **CLOSED** ปิดฝา — ดูความหนา 15.85 มม. และฝาล่าง
- **OPEN** กางจอ 112°
- **EXPLODED** แยกชิ้นตามลำดับการถอดจริง 8 ชั้น
- **SECTION** ผ่าครึ่งตามระนาบที่เลื่อนได้ (ค่าตั้งต้นผ่ากลางพัดลม x = 56 มม.)
- **X-RAY** ทำเปลือกให้โปร่งแสง เห็นข้างในโดยไม่ต้องถอด

## แบบจำลองที่ขับทุกอย่าง

หน้าปัดไม่ได้ใส่ตัวเลขไว้ล่วงหน้า ทั้งหมดคำนวณสด ๆ จาก `notebook/model.js`:

```
T_die = 25 °C + P · (Rjc + Rhp + Rsa)
```

- ฮีตซิงก์เป็นก้อนความร้อนก้อนเดียว 55 J/K ความร้อนเข้าจากซีพียู ออกทางครีบ
- `Rsa` ลดลงตามลมที่พัดลมเป่า: 5.25 K/W ตอนนิ่ง → 1.35 K/W ตอนลมเต็มที่
- พัดลมเริ่มหมุนที่ 49 °C ไล่ขึ้นเป็นเส้นตรงถึง 5500 rpm ที่ 92 °C
- ซีพียูเร่งได้ 60 W นาน 28 วินาที แล้วลงมา 28 W และถูกหรี่ลงอีกเมื่อจะเกิน 95 °C
- อุณหภูมิลมที่ออกช่องระบายคำนวณจาก `Rsa` ตัวเดียวกัน จึงร้อนเกินโลหะไม่ได้

มุมบานพับ ระยะแยกชิ้น และมุมใบพัด ก็เป็นอินพุตเดียวกันที่ส่งต่อให้ทั้งรูปทรงและหน้าปัด
ไม่มีอะไรทำ keyframe ไว้ ภาพกับตัวเลขจึงขัดกันเองไม่ได้

## โครงสร้างโค้ด

```
notebook/
  model.js    ตัวเลขจริงทั้งหมด: ขนาด, แบบจำลองความร้อน, ตารางชิ้นส่วน 22 ชิ้น (ไม่มี three.js)
  laptop.js   สร้างรูปทรงจากโค้ด ตามขนาดใน model.js — update(s) จัดท่าทุกชิ้น
  stage.js    สตูดิโอ: แสง เงา GTAO bloom
  console.js  หน้าปัด 1600 × 900 — update(s) วาดใหม่จาก state ของเฟรมนั้น
  tour.js     มุมกล้อง 7 มุม และสคริปต์ทัวร์อัตโนมัติ
  live.js     ตัวขับหน้าเว็บ: ปุ่ม สไลเดอร์ orbit การคลิกเลือกชิ้นส่วน ระดับคุณภาพอัตโนมัติ
  main.js     จุดเริ่ม
```

### สั่ง build ใหม่

```bash
node "$HOME/.claude/skills/teardown/sims/build.mjs" ./notebook
```

แล้วแก้ชื่อหน้าต่าง (build ตั้งชื่อตามชื่อโฟลเดอร์):

```bash
sed -i 's|<title>notebook</title>|<title>Notebook Anatomy</title>|' teardown-out/dist/notebook.html
```

### ถ่ายภาพไว้ตรวจงาน

สคริปต์ตรวจงานอยู่ใน scratchpad ของเซสชัน (`sheet.mjs`) สั่งหน้าเว็บผ่าน `window.LIVE.set(...)`
แล้วเรียงภาพเป็นแผ่นเดียว — `window.LIVE` เปิดไว้ให้เรียกได้จาก console เช่นกัน:

```js
LIVE.set('mode', 'explode'); LIVE.set('view', 'macro'); LIVE.set('sel', 'soc');
```
